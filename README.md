# mmCooper：仅 OPV2V 的复现结果快照

范围仅 OPV2V，不包含 DAIR-V2X、V2XSet、V2V4Real。这里是已执行结果与缺口的可核查快照，尚未完成 OPV2V 的全部论文实验。

## 已完成执行

- 74个独立执行任务：69个2170帧全量测试条件、5个计时任务。
- mmCooper自身：主条件1个、鲁棒性条件13个、车辆数量条件5个，合计19个全量条件。使用作者公开权重。
- 其余50个全量条件为公开对比基线；其中部分训练、噪声、延迟或评价口径与论文未完全对齐。执行完成不等于严格复现成功。
- mmCooper主结果：AP@0.7=78.13703358%，论文78.11%，差+0.02703358个百分点；AP@0.5=88.97076622%，论文88.93%，差+0.04076622个百分点。0失败、0跳过。
- 原主结果测试已完成；重新从零训练是另一种训练过程复现，不是承认上述测试结果有效的前提。

## 尚未完成

- Select2Col原生训练停在完整提交31/60轮；无最终AP。历史同模型吞吐估计剩余训练约70小时，恢复与评价时间另计，不是整套复现工期。

- 完整通信曲线、可比较工作点、部分基线延迟条件，以及计时口径对齐。

## 文件与核查

- `OPV2V_EXECUTION_INVENTORY.json`：74项执行元数据与原始结果文件SHA256。
- `OPV2V_PAPER_TARGETS.json`：214条论文数值目标；它们不是214个训练任务，同一测试可出现在多张表图中。
- `OPV2V_MAIN_AP07.json`、`OPV2V_REMAINING.json`、`PROVENANCE.json`：主结果、缺口、来源。
- `HASHES.json`、`verify_snapshot.py`：仅验证本快照的完整性和元数据一致性，不重新计算AP。运行 `python verify_snapshot.py`。
